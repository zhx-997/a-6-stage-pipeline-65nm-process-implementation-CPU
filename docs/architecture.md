# Architecture — 架构说明

本文件汇总从答辩 PPT 与技术文档中提取的架构要点，便于在面试中讲解设计动机、关键实现与权衡。

## 高层概览
- 目标：设计并实现一款 6‑stage 流水线 CPU，支持基本的 RISC‑V 指令子集（算术、加载/存储、分支、跳转）。
- 流水线阶段（示例）：IF → ID → EX → MEM → WB，若为 6-stage 则可为 IF → ID → EX1 → EX2 → MEM → WB（或其它拆分）。

## 关键模块
- IF / IM（指令取指与指令存储）
- ID / RF（译码与寄存器堆）
- EX / ALU（运算执行，含移位/算数/逻辑）
- MEM / DM（数据存储访问，含 SRAM 模块封装）
- WB（写回）
- Hazard Unit（转发、load-use 检测、阻塞）
- Branch predictor（小型 BTB + BHT 实现）

## 设计权衡与实现细节
- 简化的分支预测（索引窗口小、基于 PC[4:2] 索引的直接映射 BTB）以降低资源占用。
- Load-use stall 检测在 ID 阶段实现，使用流水线寄存器一致性刷新实现指令驳回（flush）。
- SRAM 使用仿真模型（TS1N65...）作为 IM/DM 的行为替换，便于与真实工艺模型对接。

## 建议面试讲点
- 为什么选择 6‑stage（性能/时序拆分）
- 如何处理数据冒险与控制冒险（转发逻辑 + BTB 简易预测）
- 在调试中遇到的典型问题（例如 load-use hazard 导致的错误写回）以及定位方法
